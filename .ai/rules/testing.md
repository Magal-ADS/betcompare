# Testes

- Use PHPUnit, conforme a configuração atual do Laravel.
- Prefira testes de feature para fluxos de coleta, normalização, comparação e dashboard; use testes unitários para regras puras e determinísticas.
- Cubra cenário de sucesso, dados ausentes, fonte indisponível e eventos sem correspondência quando aplicável.
- Não remova testes sem aprovação explícita.
